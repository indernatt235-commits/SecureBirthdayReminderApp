# Secure Birthday Reminder Application
## Project Overview

This project is a PHP and MySQL-based Birthday Reminder Web Application developed as part of my MSc Cyber Security studies.
The main purpose of this project is to understand common web application vulnerabilities and learn how to prevent them using secure coding techniques.
The project contains two versions:
- Insecure Version: Demonstrates common web application vulnerabilities.
- Secure Version: Implements security controls to protect the application.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- WAMP Server
- OWASP ZAP
- PHPStan

## Security Vulnerabilities Studied
1. SQL Injection
2. Cross-Site Scripting (XSS)
3. Insecure Direct Object Reference (IDOR)
4. Cross-Site Request Forgery (CSRF)
5. Session Security Issues
6. Security Misconfiguration

## Security Implementations
- Password hashing using password_hash()
- Password verification using password_verify()
- Prepared SQL statements
- CSRF token validation
- Output encoding using htmlspecialchars()
- Session regeneration
- Content Security Policy (CSP)
- Security HTTP headers
- User-specific data access control

## Learning Outcomes

Through this project, I gained practical knowledge of secure software development, web application vulnerabilities, vulnerability testing, and security implementation.
I also learned how to use OWASP ZAP to test web application security.

## Project Purpose

This project is developed for educational purposes to demonstrate the difference between insecure and secure software development.
